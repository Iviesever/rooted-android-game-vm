# 文件管理人工验收

这份清单只检查真实窗口操作。后台测试不能代替以下结果；未检查项保持未完成。使用独立测试应用和测试文件夹，不覆盖正式应用资源。

## 准备

关闭之前的测试工作台，再打开本次提供的候选目录中的 RootedAndroidGameVM.exe。若安卓已经运行，无需重复启动。默认工作台应只有通用应用、文件、诊断、输入和恢复能力，没有特定游戏专属操作。

## 必查操作

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 应用发现 | 文件管理中选择用户，按应用名称搜索，在下拉列表选中应用 | 有名称和图标，包名仅用于同名消歧；不需要手填包名。应用未选择时不会自动操作列表第一项 |
| 2 私有目录上传 | 选择私有数据根，双击进入 files；上传一个包含中文文件、子目录和空目录的电脑文件夹 | 选择器可操作；停止应用要求清楚；成功后列表刷新，层级和名称保持 |
| 3 私有目录导出 | 进入刚上传的文件夹，点击导出当前目录，选择电脑上的独立空目录 | 无需输入安卓路径或包名；文件和空目录齐全；后台再核对哈希 |
| 4 键盘、多选与拖放 | 选中文件夹按 Enter，使用上一级和面包屑；Ctrl/Shift 多选两个文件下载；从资源管理器拖入一个测试文件 | 目录导航正常，下载保持两项；拖入当前文件页只上传文件，不触发应用安装 |
| 5 冲突与结果 | 修改本机测试文件后再次上传同名文件，选择备份后覆盖；在传输记录选中任务并查看结果 | 显示同名差异和策略；逐项状态、错误、暂存及备份记录清楚；多页结果能继续加载 |
| 6 取消与明确续作 | 上传独立的大测试文件，传输中取消；选中记录并继续原任务 | 取消可见，已完成项不冒称全批完成；只在点击继续后恢复，最终核验；传输中切出再回到文件页仍保留取消入口 |
| 7 根目录边界 | 切换到未解锁或不可访问根；选择一个显示上传时创建的缺失应用外部根 | 旧文件列表和旧上传目标被清空；锁定根不能上传。缺失根可先计划上传，取消计划不创建，执行后刷新为真实目录 |
| 8 应用整体导出 | 点击导出应用数据，勾选私有数据及一个可访问的外部根 | 导出目标可选择，结果可追溯到原根和计划，不串应用或用户 |

反馈可直接写“1–3通过；4拖放没有反应；5待测”这样的位置和现象，不必提供截图。失败时保留原传输记录，不要反复重传；后台可按原任务编号检查原因。

全部通过后才继续最终安装候选：备份程序、正常停机覆盖、实际安装目录的关键复验、正式数据散列保持，以及精确发布资产核验。
