## Malody 与指定内容

提供的 Malody 6.6.12 APK 只有 ARM64 库。它在固定 Android 35 x86_64 镜像中通过 `libndk_translation.so` 实际启动；指定自由皮肤进入谱面时发生加载错误，已保留失败记录。

使用本机已有的正式来源 6.6.22 APK 保留数据升级后，同一份设备授权皮肤成功加载。之后再次提交 6.6.12 安装请求，工具明确保留已安装的较新版本。没有修改 APK 或绕过皮肤绑定。

虚拟机自身完成原有 D5 登记，作者用既有工具签发匹配包。没有复制其他设备私钥，也没有恢复 D6 开发。账号登录由用户亲自完成。

指定段位包的九张六轨谱面已由 Malody 解包并出现在应用内。Start Dan 在 NORMAL 下运行到结算流程（首次结算教程弹层也有记录）；9th Dan 完成上述两分钟输入测试。没有用 Autoplay 代替这两项输入验证。重试、暂停和再次加载均实际触发。测试用于验证运行链路，不以通关成绩作为结论。

## 性能与实际限制

软件渲染的游玩截图出现约 17–27 FPS，应用 PSS 样本约 1.0–1.2 GiB；CPU 样本可能累计多个核心。测试期间主机同时承担开发任务，这些不是受控性能基准。

现有 Host GPU 档位可以启动，主界面观察到约 52 FPS，但这不证明已达到稳定 60/120 FPS。Unity SurfaceView 的 gfxinfo 帧时序不可用，记录为空值而非零耗时。显示与运行性能继续由下一阶段独立测量和优化。

键音与皮肤资源未改写；主观听感不是本次自动记录可证明的结论。跨 Windows 用户的命名管道拒绝依赖系统 CurrentUserOnly 策略，本次未创建第二个 Windows 账号进行攻击测试。未做真实磁盘耗尽或主机突然断电测试，失败路径由自动测试和恢复记录覆盖相应范围。

完整 NDJSON、TRX、原始 PNG、视频、输入记录和恢复证据只保存在本机任务/资源目录中，不进入源码或公开 Release。诊断默认不导出应用私钥、登录数据库或整个私有目录。
