## 未通过项如实保留

**结项不代表整个产品物理内存≤2,000,000,000字节已经通过。** 含GUI及辅助进程的一轮游戏加载/游玩工作集观测最大值为**2,244,972,544字节**。工作集求和包含共享页重复计数，且采样存在缺失；它不是精确独占物理内存或所有瞬时峰值的证明。

768MiB组合出现系统界面无响应，部分更小配额组合发生低内存退出；相关失败配置没有作为成品交付。两种guest ANGLE路径都被固定引擎的驱动兼容性检查拒绝。用户选择保持现有驱动，因此没有更新NVIDIA/Intel驱动，也没有绕过检查。

**最终覆盖安装未执行。** 原生产安装和早期本地安装包不包含全部后续源码提交；不能把这些产物称为本次最新优化版。完整多轮2GB验收、活动GUI预览下的峰值证明、guest实验方案产品化及安装后回归，均记为未完成并随本次结项停止，不勾选为通过。
