# 双向文件操作

工作台的应用目录和文件服务面向通用安卓应用，不要求安装任何特定游戏，也不依赖插件。

## 窗口操作

1. 在“使用安卓”启动虚拟机，再进入“文件管理”。
2. 选择安卓用户，输入应用名称的一部分，在下拉列表选择应用。图标和名称用于识别；包名和用户用于区分同名应用。共享存储也可单独进入。
3. 左侧选择数据根，双击文件夹或选中后按 Enter 进入。地址、面包屑、上一级和后退用于定位；“加载下一页”继续读取大目录。
4. “上传文件…”和“上传文件夹…”选择电脑来源；也可将文件或文件夹拖入当前目录。安卓列表支持 Ctrl/Shift 多选，再“下载所选…”。“导出当前目录…”导出当前整个文件夹，“导出应用数据…”可勾选多个根，包括私有数据。
5. 同名冲突时选择保留双方、跳过或备份后覆盖。私有写入和一致性导出会列出需要停止的应用；确认按钮明确表示停止应用后传输。不能访问或未解锁的根不能写入；“上传时创建”的缺失根在执行已确认计划时才创建。
6. 在“传输记录与恢复”选中任务，查看逐项结果、问题、暂存进度与备份记录位置；结果超过一页时继续加载。取消保留真实进度，“继续原任务”核验旧任务并明确续作，不会自动重放。提交回执未知时显示待确认，不能当成成功或直接删除暂存。

传输核验表示复制内容的哈希一致，不表示应用已经读取或完成业务导入。目录合并保留目标额外文件。Windows 无法原样保存的名称或链接可改用 tar 归档；具体不可访问原因和计划问题会保留。

## AI / CLI 操作

AI 使用同一个后台，与窗口当前选择无关。完整 JSON 调用及参数见 [CLI 文档](cli.md)。

| 操作 | 命令与引用 |
| --- | --- |
| 发现用户和应用 | `users.list` → `apps.list`，按真实名称筛选，并核对 userId/package |
| 找到数据根 | 将发现的 `appRef` 传给 `files.roots`，核对 accessible/locked/creatable |
| 浏览任意层级 | `files.browse` 使用 rootRef、relativePath 和分页 cursor；条目带版本化 entryRef |
| 上传电脑目录 | `files.transfer.plan` 的来源用 localPath，目标用目录 entryRef；缺失根用 rootRef/relativePath 和 createParents |
| 导出私有目录 | 同一计划接口，来源用目录 entryRef 或根引用，目标用 localDirectory |
| 执行与核验 | 检查计划冲突、空间和应用停止要求，再 `files.transfer.start`；读取明确终态和逐项账本 |
| 取消与恢复 | `cancel` 指向原 jobId；`files.transfer.inspect` 分页读取；`files.transfer.resume` 明确继续原 planId |

引用绑定实例、用户、应用安装身份及会话，不能跨实例或重装后复用。退出窗口不会让 CLI 失去任务记录；停止安卓时仍可查看已保存的传输历史。
